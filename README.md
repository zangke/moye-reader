# 墨页

墨页是一款用 Rust 与 GPUI Kit 编写的本地电子书阅读器，支持 TXT、EPUB 和 PDF。正文、目录、PDF 页面和批注都在原生窗口内绘制，可以离线阅读。

## 打开和构建

macOS Apple 芯片版位于 `dist/墨页.app`，也可解压 `dist/墨页-macOS-arm64.zip` 后在 Finder 双击打开。打开后进入书库，点击书籍即可开始或继续阅读。首次启动可以打开带脚注的试读《雾岸来信》。

可从 [GitHub Releases](https://github.com/soandsoprogrammer/moye-reader/releases/latest) 下载发行包。

用 Rust 与 Xcode Command Line Tools 重新构建。首次构建会把对应平台的 PDFium 渲染库嵌入程序，因此需要联网下载一次：

```sh
cargo run --locked
./scripts/build-macos.sh
cargo test --locked
```

也可以在命令行里直接指定一本书，例如 `cargo run --locked -- "/path/to/book.epub"` 或 `cargo run --locked -- "/path/to/book.pdf"`。

## Windows 掌机

解压 `MoYe-Windows-x64.zip` 后打开 `MoYe.exe`。Windows 版默认使用掌机布局，附带 Noto 中文字体。桌面布局可用 `MoYe.exe --desktop` 启动。把 TXT、EPUB 或 PDF 拖到窗口即可导入，书库也可以用「导入书籍」。

把掌机的控制模式切到手柄模式，应用会识别 Windows 的 XInput 手柄。

| 按键 | 操作 |
| --- | --- |
| LB / RB | 上一页 / 下一页 |
| 方向键 | 上下或左右翻页，或在书库、目录和设置中选择 |
| A / B | 确认或继续阅读 / 返回 |
| X / Y | 切换书签 / 阅读设置 |
| View / Menu | 目录 / 批注 |

F11 可切换全屏。Windows 的书库数据位于 `%LOCALAPPDATA%\Moye Reader`。

## Steam Deck

在桌面模式解压 `MoYe-SteamDeck-x86_64.tar.gz`，运行其中的 `MoYe/launch-moye.sh`。数据会保存到用户目录；发行包附带 Noto 中文字体。若想从游戏模式启动，把这个启动脚本 [添加为非 Steam 游戏](https://help.steampowered.com/en/faqs/view/671A-4453-E8D2-323C/)。

掌机布局默认单页翻页，目录和批注作为侧边栏按需弹出。可用触屏或触控板打开书籍、选中文字和点开注标。导入书籍可在桌面模式完成，也可将 TXT、EPUB 或 PDF 路径作为参数传给启动脚本。

在 Steam Input 中可使用键盘鼠标布局，并按下表绑定常用按键。应用也响应这些键盘按键。

| 掌机按键 | 映射到 | 操作 |
| --- | --- | --- |
| L1 / R1 | Page Up / Page Down | 前后翻页 |
| 方向键 | 方向键 | 左右翻页，在书库移动焦点 |
| A / B | Enter / Esc | 打开或继续阅读 / 返回 |
| X / Y | B / T | 切换书签 / 阅读设置 |
| 背键 | C / N | 打开目录 / 批注 |

macOS 可用 `cargo run --locked -- --handheld` 预览同一布局。Steam Deck 包由 GitHub Actions 在 x86_64 Linux 上运行 `scripts/build-steamdeck.sh` 生成。

## 阅读和批注

- 阅读工具集中在左上角。左栏显示书籍和目录，可收起以腾出更多正文空间。点击书库图标返回书库，阅读位置会自动保存。
- 在书库右上角用「导入书籍」选择文件，或把文件拖到窗口。TXT 支持 UTF-8、带 BOM 的 UTF-16、GB18030（含常见 GBK 文本）和自动识别常见章节标题。EPUB 支持 EPUB 2/3 目录、书内链接、常见行内样式、封面和 PNG、JPEG、GIF、WebP 插图。PDF 保留原始分页和排版，封面取第一页，可阅读文本型、扫描型和图文混排的无密码 PDF。
- 书库按封面展示书籍，阅读进度在封面下方。长按封面或点击「选择」进入多选，可将选中的书一起移入已有或新建文件夹。在文件夹内导入会把新书归入当前文件夹。移除文件夹时，其中的书籍会回到书库首页，阅读记录随书籍保留。
- EPUB 优先显示书内目录。连续翻页按电子书的阅读顺序经过海报、版权页和续页，章节按钮按目录条目跳转。
- 拖选正文后可选三种颜色划线、添加备注或复制原文。「我的批注」可回到原文、修改备注和颜色，或删除批注。
- 点击正文里的注标，脚注、尾注和词注会在原文旁弹出。支持跨文件注释、旧式锚点、图片注标、缩写释义和 Ruby 读音。正文中的夹批、旁批、回评和校记可随原文显示，兼容常见的 EPUB 标记和文字颜色。
- EPUB 中标为「造字」「外字」或 gaiji 的字符图片可随正文排版，随字号缩放并适配明暗主题。
- 书签图标可添加或移除当前位置的书签。点击左下角「批注」或「书签」可打开阅读记录，并跳回原文。打开记录时正文不会重新排版。
- 在「阅读设置 → 阅读方式」切换滚动、单页和双页。单页和双页会随窗口和字号重排，底栏显示本章页码。用底栏按钮、上下或左右方向键、空格或 Page Up / Page Down 前后翻页。双页模式每次翻一组，每章从左页开始。
- PDF 按原页面比例显示，并参与滚动、单页和双页阅读。PDF 自带书签/大纲时，目录按章节层级列出并跳到对应页码；没有内嵌目录的 PDF 回退为逐页导航。书签和阅读位置可以保存，PDF 固定版面暂不支持选中文字、复制或文字划线批注。
- 滚动模式下，左右方向键切换章节，上下方向键、空格和 Page Up / Page Down 滚动。⌘O 导入，⌘L 在书库与阅读间切换，⌘+ / ⌘− 调字号，⌘C 复制选中正文，⌘D 添加或移除当前位置书签。「阅读设置」有纸色、明亮和夜间三种配色。

导入的书籍副本、阅读位置、偏好、书签和个人批注保存在 `~/Library/Application Support/Moye Reader/`。应用按文件内容去重，批注使用章节内的文本位置，因此切换配色、字号和窗口宽度后仍能定位。正文、目录和书库列表按视口渲染，图像按需在后台解码。

EPUB 以重排正文为主，当前兼容范围是无 DRM 的文本型电子书。复杂 CSS、固定版式和多媒体按可提取内容降级显示。

PDF 使用 PDFium 在后台按需渲染当前页，不导入时批量拆图。字体大小设置不会重排 PDF；阅读页按较清晰的屏幕像素渲染，并在翻页后自动清理远处页面的图像缓存。

## 书源插件

在顶部切换到「插件」，即可查看已安装插件、启用或停用插件。安装时点「打开插件文件夹」，把插件目录放进去，再点「刷新」。启用的书源会出现在书库的「书籍来源」中。

支持配置的插件会显示「设置」。例如在「文件夹书源 → 设置」选择书籍目录，随后就能从书库浏览并导入该目录里的 TXT、EPUB 和 PDF。

墨页只在浏览或导入时运行插件，下载完成后把书存入本地书库，之后可以离线阅读。

仓库提供可独立构建的「文件夹书源」示例，以及接入网页或云盘书源时可复用的 [插件协议和开发指南](plugins/README.md)。
